
Discover. Explore. Plan.

WanderWise is a modern travel planning platform designed to help travelers explore destinations, discover iconic attractions, stay informed with real-time weather updates, and create memorable travel experiences with the support of AI-powered trip planning.

Built with a strong focus on visual design, responsiveness, and user experience, WanderWise combines destination discovery, live travel information, and intelligent itinerary generation into a single seamless platform.

Key Highlights
🎥 Immersive landing experience with a cinematic background video
🌎 Explore destinations from around the world
🔍 Search and filter destinations effortlessly
📍 Dedicated destination pages with detailed travel insights
🏛️ Discover famous attractions and must-visit places
☁️ Real-time weather updates powered by OpenWeather API
📸 Dynamic destination imagery powered by Pexels API
🤖 AI-powered travel assistant using Google Gemini
🗓️ Day-by-day itinerary planning for smarter travel decisions
📱 Fully responsive across mobile, tablet, and desktop devices
Tech Stack

Frontend: React, React Router, JavaScript, HTML5, CSS3, Vite

APIs: OpenWeather API, Pexels API, Google Gemini API

Project Goal

The objective of WanderWise is to transform travel planning into an engaging and intuitive experience by combining beautiful design, live travel data, and AI-assisted recommendations, helping users make informed decisions before and during their journeys.
